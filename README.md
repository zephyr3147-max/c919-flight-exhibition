# 解构飞行

以C919外形和通用结构示意构成的交互数字展览。三幕入场后可自由观察飞机、搜索部件、调节展开和舵面。

## 在线体验

https://digitalmedialab.online/

## 运行

将仓库作为静态网站部署，发布目录为仓库根目录，入口为index.html。不需要构建命令。请通过HTTP服务访问，不直接以file协议打开。

主要适配桌面端，浏览器需支持WebGL2。三维库和模型均随仓库提供。
